# Reference Simulation Outputs

These files are example outputs generated from the bundled eight scenarios using the project version included with this archive. They are provided so a beginner can compare their own output structure and final state after running `hvdc-lab simulate-all`.

They are **not** evidence that you personally executed the project. When using this repository as a portfolio project, run the scenarios yourself, inspect the outputs, and retain your own test record tied to your Git commit and configuration revision.

The CSV files contain time-series snapshots. The JSON files contain the scenario definition, event sequence, and final snapshot. The UTC timestamp field records execution time and will differ when you repeat the run; the simulated event sequence and final states should follow the same training logic.

All signal values and thresholds are fictional training data. Do not use them as real HVDC settings or protection values.
